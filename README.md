# Week 1 – JeepTrail AI Dashboard

## Overview

JeepTrail AI Dashboard is a Streamlit-based data analytics application built as part of the **Mastering Agentic AI Bootcamp – Week 1 Vibe Coding Project**.

The application allows users to explore and analyze off-road trail data across the United States using interactive visualizations, filters, and dashboard metrics.

This project was developed using an AI-assisted vibe coding workflow with Claude Code and VS Code.

---

## Features

### Dashboard Metrics

* Total Trails
* Average Trail Rating
* Number of States Covered
* Average Scenic Score

### Interactive Filters

* State
* Difficulty
* Vehicle Requirement
* Trail Type

### Visualizations

* Trails by State
* Difficulty Distribution
* Top Rated Trails
* Scenic Score Distribution

### Data Exploration

* Searchable trail dataset
* Interactive filtering
* Dynamic chart updates

---

## Dataset

The project uses a synthetic dataset containing:

* 200 off-road trails
* 20 U.S. states
* Trail difficulty levels
* Vehicle requirements
* Scenic scores
* Elevation gains
* Trail types
* Estimated trail durations

Dataset file:

```text
data/trails.csv
```

```bash

```

Run the dashboard:

```bash
streamlit run app.py
```
