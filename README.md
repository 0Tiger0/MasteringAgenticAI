\# JeepTrail AI Dashboard



\## Overview



JeepTrail AI is a Streamlit-based dashboard that analyzes and visualizes off-road trail data across the United States.



\## Features



\* Interactive filtering by state, difficulty, vehicle requirement, and trail type

\* KPI metrics for trail analysis

\* Visualizations using Plotly

\* Searchable trail dataset

\* Modern dashboard UI



\## Tech Stack



\* Python

\* Streamlit

\* Pandas

\* Plotly

\* Claude Code

\* VS Code



\## Dataset



Synthetic dataset containing 200 off-road trails with:



\* Trail name

\* State

\* Difficulty

\* Length

\* Elevation gain

\* Vehicle requirement

\* Rating

\* Scenic score



\## Run Locally



```bash

pip install -r requirements.txt

streamlit run app.py

```
